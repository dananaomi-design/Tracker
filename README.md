# Dana · Plan Fase 1

App personal de seguimiento para ejercicio, hábitos y portafolio UX.

## Stack

- React 18 + Vite
- Sin dependencias de UI externas
- Persistencia en localStorage

## Setup local

```bash
npm install
npm run dev
```

## Deploy en Vercel

1. Sube este repo a GitHub
2. En [vercel.com](https://vercel.com), importa el repo
3. Framework: **Vite** (se detecta automáticamente)
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy ✓

No necesitas configurar variables de entorno.
